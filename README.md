# ZAHAB — сок пустынного трюфеля кам’а

Одностраничный сайт прямого производителя. Без сборки и зависимостей:
открыл `index.html` — работает. Всё содержимое (тексты, цены, отзывы, контакты)
лежит в одном файле `assets/js/data.js`.

---

## Как запустить

Просто откройте `index.html` двойным щелчком.

Если нужен локальный адрес (видео и карта тогда работают точно так же, как на хостинге):

```bash
node dev-server.js
```

Откроется `http://localhost:8140`.

## Что где лежит

| Файл | Что внутри |
|---|---|

| `assets/js/app.js` | Поведение: корзина, модальные окна, слайдер отзывов, карта, анимации |
| `assets/img/` | Фотографии: `shot-*.jpg` — предметная съёмка с сайта клиента, остальные из телеграм-канала `@zahab_bio` |
| `assets/img/logo.png` | Фирменный логотип (обрезаны пустые поля: было 1653×652, стало 992×321) |
| `assets/img/logo-mark.png` | Только знак — в шапке и как иконка для телефона |
| `assets/video/` | Три ролика сезона сбора оттуда же |
| `assets/img/poster-*.jpg` | Обложки роликов (кадр из самого видео) |
| `assets/fonts/` | Шрифты лежат локально — сайт работает без интернета и там, где Google Fonts недоступен |
| `dev-server.js` | Локальный просмотр |

В `assets/img/` лежит и запас неиспользованных кадров (`product-5…7`, `gallery-2`, `gallery-4`, `truffle-4`) —
можно поставить их вместо текущих, просто указав имя файла в `data.js`.

## Что менять чаще всего

Всё это — в `assets/js/data.js`:

| Что | Где именно |
|---|---|
| Цена флакона и наборов | `products[].price` |
| Названия и подписи товаров | `products[].title`, `.subtitle`, `.note`, `.badge` |
| Фото товара | `products[].image` (положите файл в `assets/img/`) |
| Телефоны WhatsApp | `contacts.whatsappMain.phone` и `contacts.whatsappRu.phone` — **только цифры**, без «+» и пробелов; `label` — как это показать на сайте |
| Телеграм | `contacts.telegram.user` |
| Часы ответа | `contacts.workingHours` |
| Отзывы | `reviews.items[]` — текст, кто написал, откуда |
| Список показаний | `conditions.items[]` |
| Инструкция по применению | `usage.steps[]` |
| Вопросы и ответы | `faq.items[]` |
| Точки на карте | `map.points[]` — название, город, координаты `lat`/`lon`, приближение `zoom` |
| Фото в галерее | `gallery.items[]` |
| Предупреждение внизу сайта | `disclaimer` |
| Заставка (фото и надписи) | `intro` + фон меняется в `index.html`: `.intro__photo { background-image: … }` |

Чтобы поменять фото заставки, положите новый файл в `assets/img/` и укажите его
в `index.html` в двух местах: `<link rel="preload" …>` и `.intro__photo { background-image: … }`.

## Как работает заказ

Сайт **ничего не собирает и никуда не отправляет**. Ни формы, ни аналитики, ни серверной части:

1. Покупатель складывает флаконы в корзину (она хранится только в его же браузере).
2. Кнопка «Заказ в WhatsApp» открывает чат с уже написанным текстом заказа —
   отправляет его сам покупатель.
3. Кнопка «Скопировать и открыть Telegram» кладёт текст в буфер обмена и открывает `@zahab_bio`.
4. В окне «Оставить заявку» поля имени и пожеланий подставляются в тот же текст —
   они существуют только в открытой вкладке.

Номера подставляются из `data.js`, отдельная кнопка — для российского номера.

## Заставка

Сделана так, чтобы на телефоне её было видно, а не «мелькнуло и пропало»:

- стили заставки продублированы прямо в `<head>` — она появляется до загрузки основного CSS;
- анимация стартует только когда страницу реально видно (`visibilityState`) и после
  первого нарисованного кадра, отсчёт времени идёт от него же;
- держится минимум 3,6 секунды, потолок ожидания загрузки — 6,5 секунды, аварийный выход — 10;
- есть кнопка «Пропустить» и клик по экрану;
- показывается при **каждой** загрузке страницы. Если захотите, чтобы в одной вкладке
  она играла только один раз, поменяйте в `index.html` `var ONCE_PER_TAB = false` на `true`;
- при `prefers-reduced-motion` анимация выключается.

## Просмотр фото и видео

Кадры в галерее и в разделе «Путь от пустыни до флакона» открываются во весь экран:

- листание стрелками, клавишами ← →, свайпом пальцем; вниз — закрыть;
- видео в просмотре идёт с органами управления и со звуком (если браузер разрешит автозапуск
  со звуком — иначе включается без него, звук вернёт кнопка в плеере);
- внизу подпись кадра и счётчик вида «3 / 15»;
- пока просмотр открыт, ролики на странице ставятся на паузу, а шапка и нижняя панель убираются;
- у каждого ролика есть постер (`assets/img/poster-*.jpg`) — это первый кадр самого видео,
  поэтому до загрузки ролика на его месте виден кадр, а не чёрный прямоугольник.

## Отзывы

Лента листается постранично: на широком экране видно три карточки, на планшете две,
на телефоне одну. Стрелки, точки под лентой и свайп пальцем — всё переключает одну и ту же
ленту; крайние стрелки гаснут, когда листать больше некуда. Тексты правятся в `reviews.items[]`.

## Мотивы оформления

Не «просто тёмное с золотом» — каждый элемент имеет источник:

| Элемент на сайте | Что это |
|---|---|
| Ленты-разделители (ромбы бордо-золото-песок) | **Саду** (السدو) — бедуинское ткачество Неджда, внесено в список ЮНЕСКО в 2020 году |
| Фоновая сетка тёмных секций | **Гирих** — исламская геометрия, восьмиконечная звезда (хатим) из двух наложенных квадратов |
| Золотые линии в заставке | **Трещины в песке** — по ним бедуины находят кам’а: над созревшим грибом земля вспучивается и трескается |
| Форма, по которой обрезано фото в блоке «Что в соке» | **Стрельчатая арка (михраб)** — форма ниши |
| Логотип, маркеры фактов, значок корзины | **Капля сока** — из фирменного знака ZAHAB |
| Название и золотая палитра | **ذهب (захаб)** — по-арабски «золото» |
| Фото на первом экране | арабская **далла** (кофейник) с трюфелями в пустыне — кадр из канала |

Палитра собрана из тех же источников: песок Нефуд `#c2703d`, бордо бедуинского
ковра `#8c2f1e`, золото `#d9a441`, ночь пустыни `#0d0a07`.

## Про тексты о здоровье

Показания, сроки и инструкция взяты из материалов производителя и переписки
с покупателями, поэтому на сайте они и поданы как слова производителя,
а не как медицинское назначение. Внизу страницы и в разделе показаний стоит
предупреждение: продукт не зарегистрирован как лекарство, не заменяет лечение,
при глаукоме и отслойке сетчатки нужно наблюдение офтальмолога, а при покраснении,
боли или ухудшении зрения — прекратить применение и обратиться к врачу.

Так сайт защищён от претензий по закону о рекламе: обещать лечение
незарегистрированным средством нельзя, рассказывать о продукте и приводить
отзывы покупателей — можно.

Отзывы — реальные сообщения из канала `@zahab_bio`, приведены без имён,
телефонов и скриншотов переписки.
